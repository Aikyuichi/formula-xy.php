# Changelog

## 0.8.0

### Added
- Added a standalone complete usage example in [example.php](example.php).
- Expanded inline documentation for public API classes and exception helpers.
- Improved clarity around formula evaluation and variable handling in the core class.
- Bug fixes

### Updated
- Refined the project documentation to better explain supported syntax, evaluation flow, and error handling.

## 0.5.0

### Added
- Initial public release of FormulaXY.
- Support for variables using `{name}` syntax.
- Numeric constants and arithmetic operators: `+`, `-`, `*`, `/`.
- Parenthesized expressions and validation for invalid syntax.
- Exception-based error handling for malformed formulas.
